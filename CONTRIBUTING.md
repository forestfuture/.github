# Contributing to ForestFuture projects

Thanks for helping! This is the default guide for every ForestFuture repository. A repository's own `CONTRIBUTING.md`, `AGENTS.md` or `docs/` take precedence over this one.

## Where things go

- **Ideas, new projects and open questions**: start a [Discussion](https://github.com/orgs/forestfuture/discussions). Talking an idea through first saves work on both sides.
- **Bugs and agreed work**: open an issue in the relevant repository, using its templates.
- **Security problems**: never in a public issue. See [`SECURITY.md`](SECURITY.md).

## Pull requests

- Start from an issue, or from a Discussion that reached a decision, so the change has an agreed scope.
- Keep each pull request to one change, with tests that prove its behavior.
- Run the repository's checks before opening it. Each repository's docs say which.
- Say in the description what changed and why. If the change differs from the plan in the issue, say how.

## Conduct

Everyone taking part follows our [Code of Conduct](CODE_OF_CONDUCT.md). Be kind, assume good intent, and critique the work, not the person. Report problems to [forestfriendswithissues@proton.me](mailto:forestfriendswithissues@proton.me).
