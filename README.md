# forestfuture/.github

The ForestFuture organization's shared GitHub files:

- **`profile/README.md`**: the org's public profile page.
- **Default community files**: `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md` and `SECURITY.md` apply to every repository in the org that doesn't have its own.
- **Discussions**: the org's Discussions live here. Use them for ideas, new projects and questions that span repositories. `DISCUSSION_TEMPLATE/` holds the forms for starting one.
