# Security policy

Please **don't** report security problems in public issues or Discussions.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open the affected repository's **Security** tab and choose **Report a vulnerability**. For d1-record, that's [reporting a vulnerability in d1-record](https://github.com/forestfuture/d1-record/security/advisories/new). Only the maintainers can see the report.

Please include:

- the affected repository and version (or commit);
- what an attacker could do, and under what conditions;
- the steps to reproduce it, or a proof of concept.

## What to expect

- **Within 7 days**, we acknowledge the report.
- **While we investigate**, we tell you what we've found at least every 14 days, until it's fixed or we've decided it isn't a vulnerability and said why.
- **When it's fixed**, we release the fix, publish a GitHub security advisory (with a CVE where one applies), and credit you in it unless you'd rather we didn't. We aim to do this within 90 days of the report, and ask that you keep the details private until then.

## Supported versions

Until a project reaches 1.0, only its latest release gets security fixes.
