# Security policy

Please **don't** report security problems in public issues or Discussions.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open the affected repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers can see the report.

Please include:

- the affected repository and version (or commit);
- what an attacker could do, and under what conditions;
- the steps to reproduce it, or a proof of concept.

We'll acknowledge the report, keep you informed as we investigate, and credit you in the fix unless you'd rather we didn't.

## Supported versions

Until a project reaches 1.0, only its latest release gets security fixes.
